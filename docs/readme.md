# libreaires' iosevka fork

this is a fork of the iosevka font, made to be the default for the Snowball NixOS setup.

this font was configurated especifically for some problems i had when finding a good pre-defined font for my setup (arial, mono and display), so then, I came across the iosevka fonts and how they were configurable and customizable.

### this font is still a work in progress, much more custom glyphs to be done, and i need to learn more of the .ptl language...
